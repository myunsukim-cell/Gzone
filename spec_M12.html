4. 웹헤즈 전달 — 실제 사이트에 넣을 것

  • 메인페이지 「이번 주 새로 추가된 강좌」: lectures where is_published and published_at ≥ 오늘−7일, published_at desc, 최대 8개. 로그인 학생이면 request_flow_id의 requester_sid=본인 건을 「내 신청 반영」으로 맨 앞. 비로그인은 학년 무관 최신순.
  • 학생 마이페이지: 2.0 학생 페이지 「다음으로」 칸과 동일(신청 폼·내 신청 상태·알림 3건). 원천 = gz_stu_req_list / gz_stu_req_submit.
  • 디자이너(선생님)·디렉터(원장) 페이지: 오거나이저 📮 칸과 동일. 원천 = gz_req_list / gz_req_submit.
  • 관리자(본점): 오거나이저 📥 본점 접수함과 동일(현황판·승인 폼·계획표·확인→반영). 원천 = gz_req_list / gz_req_act.
  • 알림은 앱 안 표시가 기본. 카톡·문자 발송은 notifications(kind=제작, status=대기)를 기존 발송함(notify_box)이 처리.
